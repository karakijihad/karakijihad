## Jihad Karaki

I lead diagnostics for one of Europe's largest metro networks and build AI agent systems. Mechanical Engineering PhD from Politecnico di Milano, based in Milan.

Most of my work sits at one intersection: **industrial systems that have to keep running, and agents that can be trusted to act.** A metro network is a good teacher for that — nothing is a test environment, false alarms have operational cost, and systems only matter if people trust them enough to use them.

### Projects

**[TESSERACT](https://github.com/karakijihad/Tesseract)** — a self-hosted personal AI agent runtime for Windows, built and released publicly.

It combines long-term memory that consolidates rather than simply accumulating context, an isolated research vault, policy-gated tools for filesystem, shell, and external actions, and durable orchestration for background and scheduled work with crash recovery. It is model-agnostic: OpenAI, Anthropic, Gemini, Grok, NVIDIA, Claude Code, Codex, Ollama, and local models can be assigned to different roles without changing the runtime.

**[trio-cc](https://github.com/karakijihad/trio-cc)** — cross-model code review for AI coding agents. Codex audits Claude-authored changes in a strictly read-only sandbox through five parallel lenses: defects, security, tests, duplication, and drift between intended and actual behavior. Claude then adjudicates every finding against evidence from the codebase rather than accepting it automatically.

**[my-claude-setup](https://github.com/karakijihad/my-claude-setup)** — a reusable operating discipline for Claude Code across repositories. It defines minimum-code rules, confirmation thresholds, planning and review requirements, security and Git protocols, and hooks that block destructive commands and staged secrets.

**SIGDX** — a condition-monitoring dashboard for metro infrastructure, built independently.

**[ProLifter](https://docs.prolifter.app/)** — commercial competition-management software for strength sports, built in C# and Unity. Handles competition setup, athlete and attempt management, role-specific live interfaces, results, multi-display operation, and recovery from interrupted competitions.

**[MetaEngineers Metaverse](https://metaverse.metaengineershub.com/)** — an interactive C#/Unity 3D platform for technical and educational experiences, including NLP-based text and voice commands for manipulating the virtual environment. [Documentation](https://metaversedocs.metaengineershub.com/)
